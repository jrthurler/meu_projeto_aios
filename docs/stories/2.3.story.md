# Story 2.3 — UI do Cardápio

## Descrição

**Como** cliente final,
**quero** ver o cardápio completo do restaurante com categorias, produtos, filtros e busca,
**para que** eu possa escolher o que pedir e adicionar itens ao carrinho antes de finalizar o pedido.

---

## Contexto Técnico

- **Arquitetura:** Server Component (page.tsx) + Client Components (filtros, modal, carrinho)
- **Dados:** Consome `GET /api/catalog/categories` e `GET /api/catalog/products` (Story 2.2)
- **Cart state:** Zustand store — pronto para Epic 3 (Checkout)
- **CSS vars:** `--color-primary` e `--color-primary-fg` disponíveis via layout (Story 1.4)
- **Branding:** Tailwind classes usando CSS vars do tenant

---

## Acceptance Criteria

### AC1 — Página do Cardápio (`/menu`)
- [ ] `app/(tenant)/menu/page.tsx` — Server Component
- [ ] Carrega categorias e todos os produtos do tenant via fetch server-side
- [ ] Renderiza seções por categoria (heading + grid de cards)
- [ ] Estado "sem produtos" quando catálogo vazio

### AC2 — Navegação por Categoria
- [ ] `CategoryNav` — Client Component com lista horizontal de categorias
- [ ] Click em categoria faz scroll suave até a seção correspondente (`id="categoria-{id}"`)
- [ ] Categoria ativa destacada com `bg-[--color-primary]` e `text-[--color-primary-fg]`

### AC3 — ProductCard
- [ ] Exibe: foto (com fallback), nome, descrição (truncada 2 linhas), preço formatado (R$)
- [ ] Badge "Indisponível" se `disponivel = false` (apenas para admins — não visível no MVP)
- [ ] Click no card abre `ProductModal`

### AC4 — Busca por Nome
- [ ] `SearchBar` — Client Component com input controlado
- [ ] Filtra localmente os produtos já carregados (sem nova requisição)
- [ ] Case-insensitive
- [ ] Limpa filtro de categoria ao buscar (ou mantém — qualquer comportamento consistente)

### AC5 — ProductModal (Detalhes + Customizações)
- [ ] Exibe foto grande, nome, descrição completa, preço base
- [ ] Para cada `GrupoCustomizacao`:
  - `tipo: "choice"` → radio buttons (obrigatorio) ou select
  - `tipo: "addon"` → checkboxes
- [ ] Seletor de quantidade (mínimo 1)
- [ ] Preço total calculado em tempo real (base + adicionais × quantidade)
- [ ] Botão "Adicionar ao Carrinho" — adiciona ao Zustand store
- [ ] Fecha modal após adicionar

### AC6 — Carrinho (Zustand Store)
- [ ] `lib/cart/store.ts` — Zustand store com:
  - `items: CartItem[]`
  - `addItem(produto, quantidade, customizacoes_selecionadas)`
  - `removeItem(itemId)`
  - `updateQuantity(itemId, quantidade)`
  - `clearCart()`
  - `total` (computed)
- [ ] `CartItem` inclui: `id`, `produto_id`, `nome`, `preco_unitario`, `quantidade`, `customizacoes_selecionadas`, `preco_total`
- [ ] Store resetado ao trocar de tenant (via `slug` como key)

### AC7 — CartButton no Header
- [ ] Badge com número de itens no carrinho
- [ ] Visível no `app/(tenant)/layout.tsx`
- [ ] Usa `--color-primary` para cor de fundo do badge

### AC8 — Testes
- [ ] Teste: `CartStore` — addItem, removeItem, updateQuantity, total correto
- [ ] Teste: `CartStore` — múltiplos itens com customizações, total acumulado
- [ ] Teste: `CartStore` — clearCart zera itens e total
