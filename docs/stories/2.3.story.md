# Story 2.3 — UI do Cardápio

## Descrição

**Como** cliente final,
**quero** ver o cardápio completo do restaurante com categorias, produtos, filtros e busca,
**para que** eu possa escolher o que pedir e adicionar itens ao carrinho antes de finalizar o pedido.

---

## Contexto Técnico

- **Arquitetura:** Server Component (page.tsx) + Client Components (filtros, modal, carrinho)
- **Dados:** Consome `GET /api/catalog/categories` e `GET /api/catalog/products` (Story 2.2)
- **Cart state:** Zustand store — pronto para Epic 3 (Checkout)
- **CSS vars:** `--color-primary` e `--color-primary-fg` disponíveis via layout (Story 1.4)
- **Branding:** Tailwind classes usando CSS vars do tenant

#### Concerns (não bloqueantes)

1. **[MEDIUM] `addon` renderiza como radio (single-select) em vez de checkboxes** — AC5 especifica `tipo: "addon"` → checkboxes. O `ProductModal` usa `input type="radio"` para todos os grupos, incluindo addons. Isso limita clientes a escolher apenas um adicional por grupo. Documentado em Completion Notes como simplificação MVP — mas pode gerar confusão UX se o restaurante configurar múltiplos adicionais. Recomendado: implementar multi-select em Epic 6.

2. **[LOW] CategoryNav sem IntersectionObserver** — A categoria ativa atualiza apenas por click, não por scroll manual. Um usuário que role a página não verá o nav atualizar automaticamente. Comportamento aceitável para MVP mas polimento esperado em versão futura.

3. **[LOW] `img` nativo em vez de `next/image`** — `ProductCard` e `ProductModal` usam `<img src>` direto. Sem lazy loading, otimização de formato (WebP/AVIF) ou `sizes` automático do Next.js Image. Para MVP com `foto_url = null` em todos os produtos de seed, impacto é zero. Migrar quando imagens reais estiverem em uso (Epic 5).

4. **[LOW] `'use client'` em `lib/cart/store.ts`** — `store.ts` não é um componente React — a diretiva `'use client'` é semanticamente incorreta para arquivos de biblioteca/store. Na prática não quebra nada pois Zustand com `create` funciona em client bundles, mas pode causar confusão para outros devs. Recomendado: remover a diretiva — o store será incluído no bundle client automaticamente por ser importado por Client Components.
