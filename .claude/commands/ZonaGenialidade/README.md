### Entry point (recommended):
```

```

### Tasks available:
- `/ZonaGenialidade:tasks:start` — Start assessment workflow
- `/ZonaGenialidade:tasks:run-assessment` — Run behavioral assessment
- `/ZonaGenialidade:tasks:analyze-genius-profile` — Analyze genius profile
- `/ZonaGenialidade:tasks:recommend-squad` — Recommend ideal squad
- `/ZonaGenialidade:tasks:generate-blueprint` — Generate monetization blueprint

## Description

Squad que identifica a zona de genialidade do usuário através de assessment
comportamental unificado (30 min max), análise multi-framework autônoma
e entrega um Blueprint completo com squad recomendado e plano de monetização.

**Target**: Alunos do Cohort Fundamentals
